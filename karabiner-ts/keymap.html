Karabiner Keymap

Every remap from karabiner-ts/index.ts, one plate per layer. Keys keep their US positions; the small corner letter is the physical key when a layer moves something.

Changed by Karabiner Key being held Unchanged Passes through as Cmd + key Blocked, types nothing

Base layer

The home-row pinky types ', the accent dead key on Brazilian - Pro (' then e is é, ' then c is ç). Only plain presses swap; Shift and the layers still use the physical keys.

Hold Right Cmd: symbols

Right Cmd stays a real Cmd, so keys without a symbol, and mouse clicks, act as Cmd + that key. : is on both v and ' while you get used to v.

Hold Tab: numbers

A numpad under the right hand. Every other letter and punctuation key is blocked, so a stray press types nothing. Only plain Tab starts the layer; Cmd+Tab, Ctrl+Tab and Shift+Tab are unchanged.

Hold Caps (Ctrl): arrows

Caps is Ctrl while held. Ctrl + h j k l are arrow keys, and other modifiers carry over, so adding Shift selects. Every other Ctrl shortcut is unchanged.
